# Monetización

Base normativa: [[Politicas-y-Limites]] (varios datos **[PV]**; revisar políticas vigentes antes de publicar).

## Principios
1. **Solo cosmética y comodidad no competitiva.** Prohibido: pagar por poder, por revivir, por saltar noches, azar de pago (cajas/huevos/llaves), ofertas con temporizador, escasez artificial agresiva.
2. Todo lo cosmético de pago existe también como objetivo jugable cuando sea razonable (los exclusivos de pago son solo estéticos).
3. Precios visibles, sin monedas intermedias confusas: Robux directos.
4. Transparente y apto para menores (Mild).

## Productos propuestos
| Producto | Tipo | Contenido |
|---|---|---|
| Pase «Farero» | Game pass | Skins exclusivas de faro y haz, título; sin ventaja de poder |
| Packs cosméticos | Developer product / pase | Conjuntos de skins de linterna y mascotas |
| «Apoya al faro» | Developer product | Donación opcional sin beneficio mecánico (+ créditos) |
| Servidor privado | Función de Roblox | Partidas con amigos |
| Cristales (opcional, Alfa+) | Developer product | Atajo para comprar cosméticos; **no** vende poder |
Descartado: «Doble XP» (presiona a niños en cooperativo), loot boxes.
